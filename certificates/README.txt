CERTIFICATES FOLDER
====================

This folder is for Apple Wallet and Google Wallet credentials.

APPLE WALLET:
-------------
Place these files here:
- certificate.pem (Your pass signing certificate)
- wwdr.pem (Apple WWDR certificate)

Get from: https://developer.apple.com/

GOOGLE WALLET:
--------------
Place this file here:
- google-wallet-credentials.json (Service account credentials)

Get from: https://console.cloud.google.com/

NOTE: Wallet integration is OPTIONAL.
The plugin works perfectly without these files.
Only add if you want Apple/Google Wallet features.
