CARD TEMPLATES FOLDER
======================

Place your JPEG card templates here.

NAMING:
-------
- template-basic.jpg     → Available to all members
- template-premium.jpg   → Premium members
- template-vip.jpg       → VIP members

You can add more:
- template-special.jpg
- template-exclusive.jpg
- template-holiday.jpg

SPECIFICATIONS:
---------------
- Format: JPEG (.jpg)
- Recommended size: 800 x 500 pixels (or larger)
- Resolution: 300 DPI for print quality
- Color mode: RGB

DESIGN TIPS:
------------
1. Leave space for text (name, message, date)
2. Text will be added at:
   - Name: Position (100, 150)
   - Message: Position (100, 250)
   - Date: Position (100, 500)

3. Design templates in:
   - Adobe Photoshop
   - Canva (https://canva.com)
   - GIMP (free)
   - Any graphic design tool

4. Test your templates after uploading!

EXAMPLE LAYOUT:
---------------
+----------------------------------+
|  [LOGO/HEADER]                  |
|                                  |
|  [Name will appear here]         |
|                                  |
|  [Message will appear here]      |
|  [across multiple lines]         |
|                                  |
|  [Date will appear here]         |
+----------------------------------+

Upload your templates to this folder to get started!
