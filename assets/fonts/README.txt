FONTS FOLDER
=============

Place TrueType font files (.ttf) here for card text.

REQUIRED:
---------
Add at least one font file named: arial.ttf

DOWNLOAD FREE FONTS:
--------------------
Google Fonts: https://fonts.google.com/
- Download any font
- Extract the .ttf file
- Rename to arial.ttf
- Upload here

POPULAR CHOICES:
----------------
- Roboto (clean, modern)
- Open Sans (readable)
- Lato (elegant)
- Montserrat (bold)
- Playfair Display (decorative)

NOTE:
-----
If no font is found, the plugin will use system default font
(text quality will be lower).

For best results, always add a TrueType font!
